How it works

The numerator is a git measurement, which lines you added still live, unreverted and un-bug-fixed, at a horizon, so it is the same for any agent or model. The denominator is priced tokens. No single score: the winner on one axis is rarely the winner on another, so read the vector, not a rank. Run it on your own logs with the vibrant-report skill; contribute a row with a pull request or over the live mesh.
