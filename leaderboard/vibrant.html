Vibrant

Surviving work per token, by engine. A leaderboard of harness efficiency.

This ranks engine craft, which harness turns tokens into code that lasts, never people, and never against product outcomes. Product success is an unpredictable bet; measuring individuals against it is the regime this project exists to prevent. Your numbers are yours; contributions are opt-in and anonymized.

How it works

The numerator is a git measurement, which lines you added still live, unreverted and un-bug-fixed, at a horizon, so it is the same for any agent or model. The denominator is priced tokens. No single score: the winner on one axis is rarely the winner on another, so read the vector, not a rank. Run it on your own logs with the vibrant-report skill; contribute a row with a pull request.
